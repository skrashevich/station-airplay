# Station AirPlay 0.3.0

- Добавлен экспериментальный вывод звука на Android ARM64 через системный OpenSL ES. Аудиобэкенд выбирается при запуске: ALSA для Linux или OpenSL ES для Android. Отдельная Android-сборка не требуется. [PR #6](https://github.com/skrashevich/station-airplay/pull/6)
- Встроенный ARM64 PCM-модуль адаптируется к нативному загрузчику Android в приватном кэше. Приёмник и декодеры по-прежнему собираются без CGO; системный `aplay`, C/NDK и отдельный Android-хелпер не нужны.
- Исправлено преждевременное закрытие буферизованного аудиопотока при получении аутентифицированного RTP-пакета без AAC access unit. Такие пакеты учитываются в транспортной последовательности без сброса декодера и без открытия аудиовыхода; некорректные непустые кадры по-прежнему отклоняются.
- Добавлены регрессионные тесты Android-загрузчика, OpenSL ES и пустых AAC-пакетов; ошибки декодирования дополнены метаданными кадра.

## Ограничения

Поддержка Android ARM64 экспериментальная: доступ к аудио зависит от разрешений прошивки. Android ARMv7 не поддерживается. Совместимость установки через YAM и конкретных профилей Android не заявляется этим релизом.
