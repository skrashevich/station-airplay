# Station AirPlay v0.1

Первый автономный выпуск приёмника аудио AirPlay 2 для Яндекс Станций с root-доступом.

- Приём AAC-LC 44,1/48 кГц и realtime ALAC 44,1 кГц от AirPlay 2.
- Встроенный вывод ALSA: `station-pcm` включён в исполняемый файл; системный `aplay` не нужен.
- Пакеты YAM v2 для 13 профилей, установщик с проверкой SHA-256, постоянное состояние сопряжения.
- Автономные архивы Linux ARM64/ARMv7 и соответствующий исходный код с зависимостями в `vendor/`.

## Установка через YAM

На Миди с установленным YAM v2:

```sh
curl -fL https://github.com/skrashevich/station-airplay/releases/download/v0.1/install-yam.sh -o /tmp/install-station-airplay-yam.sh
sh /tmp/install-station-airplay-yam.sh cucumber v0.1
station-airplay -check
station-airplay -name 'Миди AirPlay'
```

Для других моделей выберите профиль из [инструкции](https://github.com/skrashevich/station-airplay/blob/v0.1/docs/yam.md).
Тег релиза — `v0.1`, версия в манифестах YAM — `0.1.0`.

YAM пока не запускает службы: приёмник запускается отдельно или через существующий
супервизор. Требуются glibc/libasound и свободные порты приёмника. Перед запуском
остановите другой автономный или встроенный экземпляр AirPlay.
Наличие пакета профиля не подтверждает аппаратную совместимость всех прошивок.
См. [требования и ограничения](https://github.com/skrashevich/station-airplay/blob/v0.1/README.md).

Для установки из GitHub Releases ключи YAM Registry не нужны. Установка по имени
`skrashevich/station-airplay` станет доступна после отдельной публикации в реестре.
