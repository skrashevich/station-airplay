# Station AirPlay 0.2.3

- На Яндекс Станции 3 (Orion) приёмник теперь распознаёт команды управления AirPlay в штатном формате Алисы.
- Если iPhone закрыл аудиопоток после паузы, воспроизведение снова можно продолжить голосом, пока канал управления с телефоном открыт. Когда воспроизведение начинает другой отправитель, команды переключаются на него. [PR #5](https://github.com/skrashevich/station-airplay/pull/5)
- YAM учитывает конфликт с пакетами `airplay/airplay-luna` и `alice/airplay` при установке.
