# Station AirPlay v0.1.1

Обновлены описание и совместимость пакета YAM.

Самая быстрая реализация AirPlay 2 для Яндекс Станций, не требующая изменений
конфигурации станции. Используется как встроенный AirPlay-приёмник в
[quasar-bridge](https://github.com/skrashevich/quasar-bridge).

- Совместимы все Станции на Linux с glibc/ALSA и root-доступом.
- Android-модели не поддерживаются: из пакетов убраны `yandexstation_2`
  (Макс с Zigbee и без него) и `yandexstation` (первое поколение на штатной прошивке).
- Выпуск содержит пакеты для 11 профилей YAM, автономные ARM64/ARMv7-архивы,
  соответствующий исходный код и контрольные суммы SHA-256.

На колонке с настроенным официальным реестром YAM:

```sh
yam install skrashevich/station-airplay@0.1.1
station-airplay -check
station-airplay -name 'Моя Станция AirPlay'
```

Перед обновлением остановите работающий приёмник. YAM не запускает службы:
после установки приёмник запускается отдельно или через существующий супервизор.
Подробнее: [установка и совместимость](https://github.com/skrashevich/station-airplay/blob/v0.1.1/docs/yam.md).
