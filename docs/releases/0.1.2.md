# Station AirPlay 0.1.2

- YAM автоматически запускает приёмник после установки и перезагрузки станции.
  Добавлены управление службой, журналирование и сохранение выбора отключённого автозапуска при обновлении.
- Исправлен путь состояния в реальной структуре пакетов YAM. Существующие ключи
  pairing из прежнего каталога сохраняются при обновлении.
- Исправлено завершение PCM на Mini 2: однократный drain с обновлением состояния
  микшера вместо повторного сброса rate plugin. Stop во время drain корректно
  освобождает учёт потока через ALSA reset/avail_update.
- Stop сначала отправляет SIGTERM и ждёт завершения дочернего процесса,
  сохраняя отдельную семантику EOF для конечного потока.

Проверка в эмуляторе описана в [отчёте](https://github.com/skrashevich/station-airplay/blob/v0.1.2/docs/kuyase-validation.md).
