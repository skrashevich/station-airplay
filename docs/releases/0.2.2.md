# Station AirPlay 0.2.2

Исправлено совместное воспроизведение через AirPlay 2 с HomePod mini. При добавлении HomePod в группу Яндекс Станция больше не замолкает; устранены рассинхронизация и заикания при изменении состава группы.

Исправление проверено на Яндекс Станции 2 в паре с HomePod mini. Подробнее: [PR #3](https://github.com/skrashevich/station-airplay/pull/3).
